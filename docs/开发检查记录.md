## 回归重点

- 横图赠送、易拉宝收费必须独立记账，不能把收费项目错误算成 0 元。
- 非横图新增交付不自动套横图价格，须手填本次金额或明确赠送；未定价的收费项不能保存。
- 相同具体交付重复行不重复收新增交付费；后续已有横图只改尺寸不重收交付费。
- 新物料的规格关联具体对象，不覆盖原海报；复杂多项请求对象不清时保留追问。
- 原文或确认基线变化、项目被删除后，旧分析结果不再写入；连接设置变化后，旧连接测试结果立即失效。
- 连接测试必须校验模型返回的有效样本内容；空回复、无关 JSON、格式或样本不符不显示成功。
- 原预算独立保留，赠送为 0，加急须人明确勾选；所有金额来自人工设置，不由模型估价。
- 密钥不进入浏览器项目存储或导出文件，刷新后清空。

## 实际边界

开发检查使用合成订单，模型请求使用模拟返回。制作方尚未用真实密钥验证供应商连通与识别效果；实际账户可通过“测试连接”及一次完整分析自行验证。

开发检查不代表所有中文表达均可正确识别，也不能证明真实用户需求、付费意愿或节省时间。`评测方案与记录.csv` 只有表头，无评测数据行；实际评测完成前不填写用时或效果成绩。
