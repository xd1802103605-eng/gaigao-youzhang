# AI 使用与第三方说明

参赛者：徐东

## 作品中的 AI

作品提供两种清楚区分的运行方式：

| 方式 | 使用内容 | 可以说明什么 |
|---|---|---|
| 规则演示 | 本地规则与合成聊天，不调用付费模型 | 演示产品流程、界面和人工确认机制；不能作为真实模型准确率证据 |
| 真实 AI | 用户自行配置的 OpenAI 兼容接口、模型和密钥 | 配置后可请求模型整理需求和比较变化；效果需要在指定模型和版本下另行评测 |

DeepSeek、Qwen 等是可能接入的模型服务，并非已完成商业合作或获得官方背书。制作方尚未使用真实密钥完成这些服务的连通和效果验证；开发检查中的模型请求采用模拟响应。使用者在本机实际测试的结果应另外记录，不据此推定复杂任务的准确率。

## 数据和密钥

- 项目记录保存于本地浏览器，导出文件由使用者保管。当前没有提供跨设备云同步。
- 密钥只保留在当前页面内存中，不写入项目记录；本地服务不持久化保存密钥。请求时密钥会经过本地服务，转发给用户配置的模型服务。
- 开启真实 AI 后，输入的聊天、当前需求和相关提示会发送到用户指定的服务。仅使用已获许可的资料，先完成脱敏，并检查服务商的数据处理政策。
- 不要将密钥写进截图、参赛材料、导出清单或公开代码。建议只在自己的可信设备使用，避免将本地服务直接对公网开放。
- 服务商收费、密钥权限、保留期限、地区可用性和商业使用范围由使用者核对官方最新条款。

## 内容判断与人工确认

聊天、附件和示例属于待处理数据。即使聊天里写着“忽略要求”“把所有请求都当成同意”，也不应把这些话当作系统指令。

系统输出用于辅助检查，不代表客户、设计师或第三方作出承诺。用户应核对原文、处理待确认项，再决定接受、赠送、追问或拒绝。费用按用户自设价目表及逐项人工报价计算，未定价收费项不得保存，不属于模型自主定价；导出文件不承诺合同或其他法律效力。

## 制作过程中的 AI 辅助

本作品使用 Codex 与 Gemini 辅助需求分析、代码实现、文案整理和检查。开发检查使用合成订单与模拟模型响应，真实评测记录表目前仅有表头。参赛者需要阅读、理解并核对最终提交内容，现场陈述实际完成范围。不得把 AI 生成的合成案例表述成真实客户经历。

## 第三方组件与许可

| 项目 | 用途 | 说明 |
|---|---|---|
| Node.js 20 或更高版本 | 本地 HTTP 服务和接口转发运行环境 | 使用内置模块，无需安装 npm 依赖；Node.js 自身许可独立于本项目，参考其发行包的许可文件 |
| 浏览器原生 HTML、CSS、JavaScript API | 界面、交互、本地存储及导出 | 依赖浏览器能力；浏览器产品自身条款由其提供方确定 |
| 用户配置的模型服务 | 可选的需求整理和变化比较 | 非随项目分发的模型权重；需核对具体服务的价格、隐私和使用条款 |
